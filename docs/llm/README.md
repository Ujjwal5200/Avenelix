# LLM Guidance

This directory contains the operating instructions for AI agents/LLMs working with Avenelix.

- `system-prompt.md` — the primary system-style prompt for a new LLM/thread.
- `working-principles.md` — durable collaboration rules and common failure modes to avoid.

A new agent should read `system-prompt.md` first, then `docs/agent-handoff.md` and the relevant project documentation.

These files are **internal planning documentation**. Do not expose them through the public Avenelix website or public-facing product copy.
