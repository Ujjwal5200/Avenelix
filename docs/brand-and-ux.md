# Avenelix Brand & UX Direction

## Core impression

The first interaction with Avenelix should communicate:

> **Something intelligent and technically serious is being built here.**

The coming-soon page is the visitor's first evidence of the brand. It should feel intentional even though the product is not yet public.

## Audience

The page must work for both:

- developers/technical people, who may read the visual language as systems/AI/engineering;
- non-technical visitors, who should simply understand that Avenelix is a technology company building something.

## Visual language

Preferred:

- black / near-black foundation
- restrained grayscale/white highlights
- high contrast typography
- subtle depth
- abstract computational forms
- motion that feels physical/systemic
- whitespace
- precision

Avoid:

- generic blue AI branding
- excessive neon
- stock AI imagery
- literal Earth/globe imagery
- crypto-style visuals
- generic SaaS gradients
- excessive glassmorphism
- cheesy “AI brain” graphics
- unnecessary UI clutter

## Central visual

The central asset evolved from a globe-like concept into an **abstract AI eye/core**.

It should not read as an actual human eye. It is a visual metaphor for perception, intelligence, computation and systems.

The orbiting rings represent interacting layers/systems rather than planets.

The visual should feel seamless: rings, core, glow and motion should feel like one system rather than disconnected objects placed around a ball.

## Interaction

Interaction should reward attention without becoming a gimmick.

The pupil/core may subtly track cursor movement when the cursor is near the visual. Tracking should be:

- small
- eased
- non-snappy
- non-cartoonish
- disabled/reduced for users who prefer reduced motion

The page should still look complete and intentional when completely static.

## Typography / copy

Copy should be concise. Avoid exaggerated claims.

Current positioning:

**AI · Software · Systems**

**Engineering intelligent products for what comes next.**

Supporting idea:

**AI systems, software and SaaS — built from idea to production.**

This is intentionally broad because the exact business/product direction is not finalized.

## Contact

`hello@avenelix.com` is the preferred early-stage contact identity.

The visitor should have an obvious way to contact Avenelix without needing a form backend during the coming-soon stage.

## Responsive design

The experience must work across:

- mobile portrait
- mobile landscape
- laptop
- desktop
- large desktop displays
- browser zoom

Avoid fixed-pixel layouts that break when zooming. Prefer responsive sizing, `clamp()`, flexible containers, relative units and graceful overflow behavior.

## Design quality bar

Before accepting a visual change, ask:

1. Does it make Avenelix feel more like a serious technology/product studio?
2. Does it improve the composition, not merely add effects?
3. Does it still work on mobile?
4. Does it remain coherent at different viewport sizes and zoom levels?
5. Does it avoid looking like a generic AI template?
6. Is the interaction subtle enough that the user notices the product, not the implementation?

If the answer is no, don't add the effect.
