# Code Documentation

This folder contains implementation-specific documentation for the Avenelix codebase.

## Contents

- `implementation.md` — How the landing page is built, file structure, and key patterns.
- `css-architecture.md` — CSS organization, custom properties, responsive strategy, and animation system.
- `js-behavior.md` — JavaScript interaction patterns, animation logic, and accessibility guards.
- `assets.md` — Asset inventory, brand mark notes, and favicon strategy.

## Current design direction

Docs in this folder reflect the **Cinematic Dark** redesign: dark animated gradient, ambient cursor light, grain overlay, refined typography, minimal motion, and full `prefers-reduced-motion` support.

## Relationship to other docs

- `docs/README.md` — Navigation for all project docs.
- Strategy and business docs remain in the parent `docs/` folder.
- Agent/LLM instructions remain in `docs/llm/`.
