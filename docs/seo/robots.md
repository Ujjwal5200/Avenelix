# robots.txt

## Purpose

`robots.txt` tells search-engine crawlers which parts of the website they may crawl.

## Current role

Avenelix's public site is currently intended to be crawlable, so the file allows normal crawling and points crawlers to the sitemap.

## Important location rule

The live file must stay at the repository root so it is deployed as:

`https://avenelix.com/robots.txt`

Do not move the live file into `docs/seo/`.
