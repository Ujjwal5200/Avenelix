# sitemap.xml

## Purpose

`sitemap.xml` lists important public URLs that Avenelix wants search engines to discover and crawl.

## Current scope

The site is currently a single-page coming-soon experience, so the sitemap contains the canonical homepage:

`https://avenelix.com/`

As the site grows, add meaningful public pages to the sitemap when they actually exist.

## Important location rule

The live sitemap must stay at the repository root so it is deployed as:

`https://avenelix.com/sitemap.xml`

Do not move the live file into `docs/seo/`.
